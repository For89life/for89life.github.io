# Монгол вэбийн бичвэрийн жишиг

Монголын тэргүүлэх сайтуудыг судалж гаргасан дүрэм. Зорилго нь
орчуулга шиг биш, монголоор бичигдсэн шиг уншигдах бичвэр.

**Судалсан сайтууд:** ХААН Банк (санхүү), Интермед (эрүүл мэнд),
МУИС (боловсрол), Модерн Номадс / Nomads Hospitality (ресторан,
зочлох үйлчилгээ), Shoppy.mn (онлайн худалдаа), Unegui.mn (зар).

**Хуулбарлаагүй.** Эдгээрээс зөвхөн хэлний БҮТЦИЙГ авсан: нэр
томьёо, өгүүлбэрийн хэмнэл, хэсгийн нэршил, тоо/үнэ/хаяг бичих
жишиг. Бичвэр бүр өөрийн эх зохиомж. Загваруудыг үйлчлүүлэгчдэд
борлуулдаг тул бусдын өгүүлбэрийг хуулбал зохиогчийн эрхийн
эрсдэл манай нэр дээр очно.

---

## 1. Хамгийн том ялгаа: өгүүлбэр биш, холбоо үг

Манай одоогийн бичвэр тайлбарласан бүтэн өгүүлбэр ашигладаг.
Монгол сайтууд богино, зэрэгцүүлсэн холбоо үг хэрэглэдэг.

| Буруу (одоогийн) | Зөв (жишгийн дагуу) |
|---|---|
| Уламжлалт монгол хоолыг орчин үеийн үйлчилгээтэй хослуулан санал болгоно | Уламжлалт хоол, орчин үеийн үйлчилгээ |
| Өглөө кофе уух, орой коктейль амтлах боломжтой | Өдрийн кофе, шөнийн коктейль |
| Ажлын өдрийн завгүй цагт тохиромжтой шуурхай сонголтууд | Ажлын өдрийн шуурхай сонголт |

**Дүрэм:** картын тайлбар 3–7 үг. Хоёр хэсгийг таслалаар
зэрэгцүүлнэ. Үйл үг заавал хэрэггүй.

## 2. Товчны стандарт нэр

Монгол сайтууд цөөн хэдэн товчны үгийг тогтмол хэрэглэдэг.
Манай 51 хуудсанд 20 гаруй өөр хувилбар байна — үүнийг цэгцэлнэ.

| Үүрэг | Стандарт |
|---|---|
| Дэлгэрэнгүй унших | **Дэлгэрэнгүй** |
| Бүх жагсаалт руу | **Бүгдийг үзэх →** |
| Холбогдох | **Холбоо барих** |
| Үнэ асуух | **Үнийн санал авах** |
| Цаг товлох | **Цаг авах** |
| Захиалга өгөх | **Захиалах** |
| Бүртгүүлэх | **Бүртгүүлэх** |

«Үзэх үү», «Харцгаая», «Одоо дар» гэх мэт чөлөөт хувилбар
хэрэглэхгүй.

## 3. Уриалга: нөхцөл үйл үг + хүндэтгэлийн тушаал

Монгол арилжааны бичвэрийн хамгийн онцлог бүтэц:

> **[нөхцөл: -аад/-ээд, -н] + [тушаал: -аарай/-ээрэй]**

- Утсаа бүртгүүл**ээд** хөнгөлөлт**өө** ав**аарай**
- Маягтаа бөглөөд илгээ**гээрэй**
- Нэвтр**эн** эрх**ээ** шалга**арай**

«Бид танд туслахад баяртай байх болно» гэх мэт орчуулгын
хэллэг хэрэглэхгүй.

## 4. Хэсгийн дээд шошго — ТОМ ҮСЭГ

Богино, 1–3 үг, том үсгээр. Тоо нэмж болно.

Том үсэг рүү хөрвүүлэхийг **CSS-ийн `text-transform`-оор** хийнэ, эх
кодод томоор бичихгүй. Иймээс HTML-д давхар бичих шаардлагагүй;
бас дэлгэц уншигч том үсгийг үсэг тусбүрээр унших эрсдэлгүй болно.

Өдрийн огноо, төлөв заасан тэмдэг (`◷ Элсэлт 5-р сарын 15 хүртэл`)
том үсэг БИШ — тэдгээр нь хашгирах биш, мэдээлэх зорилготой.

```
ҮЙЛЧИЛГЭЭ        БАГЦ ШИНЖИЛГЭЭ      МАНАЙ БАГ
01 БЭЛЭН ЗАГВАР  ИДЭВХТЭЙ САНАЛ      АРГА ХЭМЖЭЭ
```

## 5. Тоон үзүүлэлт

Тоо дээр, тайлбар доор нь ТОМ ҮСГЭЭР эсвэл жижгээр.

```
2003                 20+              48
ҮҮСГЭН БАЙГУУЛАГДСАН САЛБАР, ЦЭГ      судалгааны нэгж
```

Тайлбар нь нэрлэсэн хэлбэртэй («салбар, цэг»), өгүүлбэр биш.

## 6. Үнэ, тоо, огноо, хаяг, утас

**Үнэ.** Мянгатыг таслалаар, тэмдэг ард: `120,000₮`
Том дүнд: `₮6.8 тэрбум` эсвэл `100 сая төгрөг`
«-с» залгавар: `95,000₮-с`

**Огноо.** `2026.03.04` (жагсаалтад) · `2026 оны 3 дугаар сар`
(бичвэрт) · `2026 ОНЫ 3-Р САР` (шошго)

**Гараг.** Да, Мя, Лх, Пү, Ба, Бя, Ня
Хуваарьт: `Да–Ба 09:00–18:00` · `Бя, Ня 10:00–16:00`

**Утас.** `7210-0262` · `+976 7210-0262` · тусгай: `1800-1234`

**Хаяг.** Хот → дүүрэг → хороо → гудамж, дугаар
`Улаанбаатар, Хан-Уул дүүрэг, 15-р хороо, Чингисийн өргөн чөлөө 6`

## 7. Байгууллагын өгүүлэмж

- Одоо цагийн үргэлжилсэн: «...ажиллаж байна», «...бэлтгэдэг»
- Мэдээний төгсгөл: **-лаа/-лээ** («нэвтрүүллээ», «хамрагдлаа»)
- Боломжийн хэлбэр: «Та ... боломжтой», «...болно»
- Хүндэтгэлийн **Та** албан ёсны бичвэрт том үсгээр
