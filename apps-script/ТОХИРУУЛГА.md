# Формын мэдээллийг Gmail болон Google Sheet рүү холбох

Сайт дээрх **«Илгээх»** болон **«Үнийн санал хүсэх»** товч дарахад мэдээлэл
Google Sheet-д мөр болж нэмэгдэж, зэрэг таны Gmail руу мэдэгдэл ирнэ.

Энэ хэсгийг зөвхөн та өөрөө хийж чадна — таны Google бүртгэлийн нэрийн
өмнөөс скрипт байршуулах эрх шаардлагатай. Доорх 6 алхам, ойролцоогоор
5 минут.

---

## 1. Хүснэгт үүсгэх

[sheets.new](https://sheets.new) руу орж шинэ хүснэгт үүсгээд нэрийг нь
жишээ нь **Gerelt — Хүсэлтүүд** гэж өгнө. Хуудсыг гараар бэлдэх
шаардлагагүй, скрипт өөрөө толгой мөрийг үүсгэнэ.

## 2. Скрипт нээх

Тэр хүснэгт дотроосоо цэсний **Extensions → Apps Script** сонгоно.
Шинэ таб нээгдэнэ.

## 3. Кодыг буулгах

Нээгдсэн `Code.gs` доторх бүх кодыг устгаад, энэ хавтас доторх
[`Code.gs`](Code.gs) файлын агуулгыг бүхэлд нь хуулж тавина.

Дээд талын хоёр мөрийг шалгана:

```js
var NOTIFY_EMAIL = 'gereltsolutions01@gmail.com';   // мэдэгдэл ирэх хаяг
var SHEET_ID = '';                                   // хүснэгтээс үүсгэсэн бол хоосон
```

Өөр имэйл рүү мэдэгдэл авах бол `NOTIFY_EMAIL`-ыг солино.

Дараа нь диск дүрс (Save) дарж хадгална.

## 4. Вэб апп болгож байршуулах

Баруун дээд булангийн **Deploy → New deployment** дарна.

- Ард талын араа дүрс дээр дарж **Web app** сонгоно
- **Description**: `Gerelt формууд`
- **Execute as**: `Me` (таны бүртгэл)
- **Who has access**: **`Anyone`** ← энэ чухал. `Anyone with Google account`
  биш, зөвхөн **`Anyone`** байх ёстой, эс бөгөөс сайтаас хүсэлт очихгүй.
- **Deploy** дарна

Эхний удаад Google зөвшөөрөл асууна:
**Authorize access → бүртгэлээ сонгох → Advanced → Go to … (unsafe) →
Allow**. «Unsafe» гэдэг нь өөрийн бичсэн скрипт Google-д баталгаажаагүй
гэсэн үг, өөр асуудал биш.

Төгсгөлд нь **Web app URL** гарч ирнэ. Иймэрхүү харагдана:

```
https://script.google.com/macros/s/AKfycb.................../exec
```

Түүнийг хуулж авна.

## 5. Хаягийг сайтад тавих

`index.html` файлыг нээж, `FORM_ENDPOINT` гэсэн мөрийг олоод (файлын
доод хэсэгт, `// ── ГАДААД ХҮЛЭЭН АВАГЧ` тайлбарын доор) хаягаа
хашилтын дунд тавина:

```js
var FORM_ENDPOINT='https://script.google.com/macros/s/AKfycb.../exec';
```

Хадгалаад сайтаа шинэчилнэ.

## 6. Шалгах

Сайт дээрээ форм бөглөж илгээгээд:

- Google Sheet дээр шинэ мөр нэмэгдсэн эсэх
- Gmail-д мэдэгдэл ирсэн эсэх

Хоёулаа ирвэл боллоо.

---

## Тэмдэглэл

- **Хаяг тавихаас өмнө** формууд ажиллах боловч мэдээлэл зөвхөн тухайн
  хөтөч дотор (сайтын админ панелд) хадгалагдана. Хаяг тавьсны дараа
  хоёулаа зэрэг ажиллана.
- Хариу мессеж бичихдээ шууд **Reply** дарж болно — илгээгчийн имэйлийг
  `replyTo` болгож тавьсан.
- Скриптийн кодыг өөрчилсөн бол **Deploy → Manage deployments →
  харандаа → Version: New version → Deploy** гэж дахин байршуулна.
  Эс бөгөөс хуучин хувилбар ажиллаж байх болно.
- Apps Script-ийн үнэгүй хязгаар: өдөрт 100 имэйл. Энэ хэмжээний
  хүсэлтэд хангалттай.
- Мэдээлэл зөвхөн таны Google бүртгэл дотор хадгалагдана, гуравдагч
  этгээдийн үйлчилгээ ашиглаагүй.
